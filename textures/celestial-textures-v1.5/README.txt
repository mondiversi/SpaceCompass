Space Compass external graphics pack 1.5

For Space Compass 1.4.4. The APK downloads files individually, never an archive.
56 full images (55 at 2048 x 1024, LV-426 at its original 1774 x 887) and
56 independent 128 x 128 previews. All files use WebP, quality 90, method 6.
Full image bytes: 12,135,510. Preview bytes: 228,784.

Catalogue, live and captured glyphs request previews only; Observatory views and
image exports request full images when needed. Lunar phase remains dynamic.
Each file has its own APK-pinned size, dimensions and SHA-256. Verified files are
cached offline; matching previous full-image caches are reused without deletion.
Unavailable resources keep the corresponding code-rendered placeholder.

See manifest.json for sources, processing, credits, licences, parent-image links
and integrity values; CREDITS.md for readable attribution; SHA256SUMS.txt for checksums.
Previous graphics releases and individual URLs remain available for older APKs.
No complete texture ZIP is distributed. No celestial photographs are in the APK.
