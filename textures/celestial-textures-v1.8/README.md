# Celestial textures 1.8

External graphics for Space Compass 1.7.0: **189 full images and 189 independent thumbnails**.
The complete logical image collection is **43,663,574 bytes (43.66 MB)**: 42,855,924 bytes of full images and 807,650 bytes of thumbnails, excluding index, credits and checksums.

This incremental release adds **five photographs and five 128×128 thumbnails**, totalling **444,858 image bytes**. The manifest also references unchanged resources in immutable graphics releases 1.6 and 1.7. Files are downloaded individually only when needed and retained in an offline cache.

All new images use WebP quality 90, method 6. Full photographs are 2048×1024; preview images are 128×128. Images preserve their source aspect ratio inside the documented derivative; credits and per-file provenance are included. Objects without a photograph remain usable with an appropriate symbolic renderer.

There is no complete graphics ZIP. Existing release assets and cache compatibility remain intact. Manifest, credits, naming rules and SHA-256 checksums accompany the ten new WebP resources.
