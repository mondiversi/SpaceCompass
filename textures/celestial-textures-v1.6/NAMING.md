# Stable graphic filenames

Lowercase ASCII and underscores only. A full image uses `{category}_{stable_identifier}.webp`.
Its thumbnail uses the identical name preceded only by `thumb_`.

Examples: `moon_jpl_0601.webp` and `thumb_moon_jpl_0601.webp`,
`galaxy_ngc_3031.webp` and `thumb_galaxy_ngc_3031.webp`.

Identifiers come from JPL, NORAD, HIP, NGC/IC, numbered minor planets or their stable designations.
The name contains neither a localized display name nor a quality, date, version or preview suffix.
An object's identity does not change when its translations or display ordering change.
An unnumbered object's first adopted designation stays stable when a later catalogue gives it a number.
The manifest retains old names as aliases; released URLs and cached files are not removed.
