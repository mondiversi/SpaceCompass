# Celestial identity in object details

The first Name field shows the localized common name, then a distinct catalogue
designation when available and a localized singular classification. Stellar spectral
classes reuse the existing qualified reference facts. Identifiers stay in canonical
form, independent of number/unit preferences, and their accessible text is not clipped.

The Moon is Earth I; Io and Europa are Jupiter I and II; Titan is Saturn VI.
These are formal satellite designations in the USGS/IAU nomenclature table:
https://planetarynames.wr.usgs.gov/Page/Planets
The Sun's spectral type is G2 V, as documented in NASA's fact sheets:
https://science.nasa.gov/sun/facts/
https://nssdc.gsfc.nasa.gov/planetary/factsheet/sunfact.html

Stellar Bayer identifiers and nebula/cluster catalogue aliases use the existing
SIMBAD/reference catalogue identifications, including alpha Ursae Minoris, alpha
Centauri AB/C, alpha Canis Majoris, alpha Orionis, beta Orionis, M42/NGC 1976 and
M45/Melotte 22. See DEEP_SKY.md and the CDS database:
https://simbad.cds.unistra.fr/simbad/sim-basic?Ident=Rigel
https://simbad.cds.unistra.fr/simbad/sim-basic?Ident=Proxima+Centauri
https://simbad.cds.unistra.fr/simbad/sim-basic?Ident=Polaris

Pluto and Sedna keep their numbered designations (134340) and (90377); Halley is
1P/Halley. Sedna is explicitly a dwarf-planet candidate, not newly classified as
an officially recognized dwarf planet. The fictional satellite remains explicitly
fictional. No additional formal solar name, fictional catalogue ID or universal
Starlink identifier is invented. Existing pointing coordinates and physical/unit
calculations are unchanged; this is reference metadata for the detail view.
