# Space Compass 1.7.5 release

Release dated 2026-11-01. Android/display version 1.7.5, monotonic version code 61,
application ID `me.mondiversi.spacecompass`, minimum Android API 26. Updates retain
the existing distribution certificate and preserve installed application data.

## Scope

Key events adds a separate inspected-object/effective-Location annual calendar,
independent consultation year, local elevations and actionable date/time links.
Date selection shares the atomic operation already used by Key heights, preserving
spatial settings and pausing the configured instant. Full-year unsupported orbital
coverage remains unavailable rather than extrapolated. Eclipses are outside this
implementation. See [scientific scope and numerical conventions](KEY_EVENTS.md).

Frozen annual CSV/TXT export shares the global selected/international profile and
position-disclosure policy. Cache keys follow object/year/zone/accepted observer and
relevant ephemerides; exact manual changes invalidate them while ordinary GPS drift
does not cause repeated loading. Results are computed off the main thread.

Live orbit/reference caption placement uses shared measured clearance and stable
above/below choices. Main landscape width is 60% sky and 40% information with a
readability fallback and a separate second line for GPS altitude uncertainty. Reordered controls, compact capture and hardware-clamped
wide default zoom retain saved choices. Selected-subset marker composition and
navigation reduce panel-animation work without changing its 300 ms duration.

## Verification

The release gate requires debug/release compilation, all 1,506 JVM tests, Android
test-source compilation, release lint, generated catalogue/identity/thumbnail
reproducibility, twenty-language key/placeholder parity, APK signing/alignment and
embedded source-commit checks. Connected instrumentation is not executed against
the personal phone. Native device checks cover real installed navigation, news,
Key events/year/export entry and 60/40 responsive layout; performed checks are
recorded separately in release metadata. Publication waits for hosted Android checks.

## Assets and compatibility

Graphics collection 1.8 is unchanged. Its 189 external WebP images and 189 independent
previews retain individual URLs, checksums and offline caching; celestial photographs
are not added to the APK and no complete texture ZIP is created. The optional information
archive contains reference/localization documentation, not runtime graphics or device
data. APK and update-index hashes refer to the exact tagged source. Private signing
material remains outside Git and every uploaded artifact.
