# Space Compass 1.7.3 release audit

Version 1.7.3 uses Android code 59 and the existing package and distribution certificate. Observatory compares upper culminations across the observation-zone calendar year, using the effective Location position and altitude. Annual minimum means the lowest upper culmination. Mid-height passages choose actual upper culminations nearest the mean of the annual extreme heights; no interpolated off-culmination time is presented as a daily high point. Each available moment configures the exact Location instant and enabled 0× clock in one preference edit, preserving spatial and resumption choices.

Annual search is cancellable and cached independently from live clock ticks. Incomplete annual ephemerides and short-lived satellite data are explicitly unavailable, without extrapolation. Observatory and Daily path keep independent per-object scroll positions during the activity session, including configuration changes and normal backgrounding. Temporary shorter loading content cannot erase the requested offset. Daily path retains quick-return header visibility and first visits still support point centering. Positions are memory-only and do not enter preferences or Location exports.

## Validation boundary

Android test compilation is not reported as executed instrumentation.

Local physical-phone checks verified annual solar solstice/equinox-region culmination dates and seasonal UTC offsets in both orientations. Independent numerical tests cover lunar topocentric heights, multiple passages, hemispheres, DST/leap years, poles, coverage failure and cancellation. Scroll checks on the phone compared the same visible text anchors and offsets after reopening Observatory and Daily path, switching Sun/Moon, rotating and resuming from background. User Location, scene selections, active object, panels and rotation were restored. The final versioned APK receives its own installation and visible version/news check; final results and hosted CI are recorded in release metadata.
