# Space Compass 1.7.3 release audit

Version 1.7.3 uses Android code 59 and the existing package and distribution certificate. Observatory compares upper culminations across the observation-zone calendar year, using the effective Location position and altitude. Significant local maxima and minima are retained throughout the year, not limited to one absolute pair. Event counts depend on object and location; the equatorial Sun has two peaks, two troughs and four mid-height passages. A 0.01-degree prominence threshold rejects tiny ripples; flat peaks select one real middle transit and the absolute bounded-year extremes remain represented. Calendar edges are not cyclically joined. These are extrema of upper culminations, not nightly lower transits. Mid-height passages choose actual upper culminations nearest the mean of the annual extreme heights; no interpolated off-culmination time is presented as a daily high point. Every event displays its date, local time, UTC offset and calculated elevation in degrees, using the user’s number format. Each available moment configures the exact Location instant and enabled 0× clock in one preference edit, preserving spatial and resumption choices.

Annual search is cancellable and cached independently from live clock ticks. Incomplete annual ephemerides and short-lived satellite data are explicitly unavailable, without extrapolation. Observatory and Daily path keep independent per-object scroll positions during the activity session, including configuration changes and normal backgrounding. Temporary shorter loading content cannot erase the requested offset. Daily path retains quick-return header visibility and first visits still support point centering. Positions are memory-only and do not enter preferences or Location exports.

## Validation boundary

Required verification covers debug/release compilation, 1,442 JVM regression tests, Android test-source compilation, release lint, twenty-language keys/placeholders and news, catalogue/identity/thumbnail reproducibility, external graphics hashes, signing identity, APK alignment and exact source agreement. Android test compilation is not reported as executed instrumentation.

Local physical-phone checks verified annual solar solstice/equinox-region culmination dates and seasonal UTC offsets in both orientations. Independent numerical tests cover lunar topocentric heights, multiple passages, hemispheres, DST/leap years, poles, coverage failure and cancellation. Scroll checks on the phone compared the same visible text anchors and offsets after reopening Observatory and Daily path, switching Sun/Moon, rotating and resuming from background. User Location, scene selections, active object, panels and rotation were restored. The final versioned APK receives its own installation and visible version/news check; final results and hosted CI are recorded in release metadata.

## Distribution

Six in-app news summaries are refreshed in all twenty languages. Graphics collection 1.8 remains unchanged: 189 full WebP images and 189 independent previews, totaling 43,663,574 image bytes, with existing quality, dimensions, credits, integrity pins and individual downloads. No new graphics release or complete texture ZIP is created. The optional information archive contains public reference tables, documentation, translations and licenses; no private device data, credentials, recordings or celestial photographs. Prior releases and their URLs remain available.

## Same-version refresh

The existing v1.7.3 release and tag are refreshed in place, retaining Android code 59 and the release ID. The source, APK, signed update index, optional information archive, checksums and validation metadata remain aligned. New regressions cover equatorial and tropical solar extrema, both hemispheres, lunar cycles, unequal local extrema, plateaus, tiny ripples, monotonic year boundaries and invalid input. Native phone checks verified date/time/elevation readouts in portrait and landscape. Older 1.7.3 installations require a manual APK reinstall because the updater deliberately ignores equal version codes.
