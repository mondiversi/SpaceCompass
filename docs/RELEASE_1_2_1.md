# Space Compass 1.2.1

Identity: version 1.2.1, version code 22, package me.mondiversi.spacecompass,
tag v1.2.1. Android 8.0/API 26 or newer. This maintenance release preserves
preferences, selections, the distribution certificate and existing image caches.
The 20 in-app news files and their 1.2.0 summaries are unchanged.

Daily-path rows place the point name above its clock and relative time. Current,
rise, culmination, set and minimum rows use theme-aware gray highlights. Photo
and panorama labels include frozen current/key-event captions, measured layout,
priority placement, unobstructed text and stronger path-colored outlines.

The pointing-reference button selects either the camera axis or the phone's
physical top edge. Its neutral perspective icons distinguish upright and flat
poses. The choice is saved; real camera mode temporarily disables the virtual
reference and retains the optical axis. Orientation is consistent across display
rotation. Status notices retain their alignment with the shutter/chevron row.

Image pack celestial-textures-v1.1 remains pinned by exact URL, size, hash and
dimensions. No external images or legacy release assets are replaced. The
optional graphics ZIP is the exact existing pack archive. The information ZIP
is regenerated for this version, retaining all source/license qualifications.

Validation covers debug/release builds, 780 JVM tests, Android test-source
compilation, release lint, twenty-language key/placeholder parity, source review,
signature/package/version and 16 KiB alignment, a physical-phone update, hosted
Android checks and anonymous release-download verification. Android UI test
sources are compiled; the full connected instrumentation suite is not executed
on the personal phone. The physical device is not rebooted during preference
checks; both references were tested after complete app-process restarts.

The signed update index uses code 22. Exact artifact sizes, SHA-256 values and
validation results are recorded in release-metadata.json and SHA256SUMS.txt.
