# Space Compass 1.1.3

Identity: version 1.1.3, version code 20, package me.mondiversi.spacecompass,
tag v1.1.3. Android 8.0/API 26 or newer. Updates preserve the existing project
signature and app-private settings, selections and downloaded map files.

This release includes all local changes since 1.1.0: the aligned star background,
verified image downloads, 2K Io/Europa maps, shared weather rendering, camera-zoom
retention, compact viewer zoom and interface/settings refinements. Six current
news summaries are translated in all 20 supported language catalogs.

The APK contains the scientific reference data, translations, bundled 4K star
atlas and original fictional LV-426 map. Twelve public planet maps remain in the
separate celestial-textures-v1 release and are downloaded individually. Legacy
Io/Europa assets remain immutable for old builds. Optional release ZIP archives
collect current graphics and the information, source notices and reference data
for independent inspection; installation does not require either ZIP.

Release validation comprises debug/release builds, JVM tests, Android test-source
compilation, release lint, signature/version/16 KiB alignment checks, focused
physical-phone review, hosted Android checks and public download checksums.
Android instrumentation compilation is distinct from execution: the full
connected-device suite is not executed on the personal phone. Public results and
file sizes are recorded in release-metadata.json; every published file is listed
in SHA256SUMS.txt. The APK and signed update index identify the exact tagged source
commit. No private key, local configuration or personal location is distributed.
