# GitHub distribution

Space Compass is distributed as a signed APK through
[GitHub Releases](https://github.com/mondiversi/SpaceCompass/releases).
The current stable release is **1.2.4**, tagged **v1.2.4**, application ID
`me.mondiversi.spacecompass`, Android version name **1.2.4**, version code **25**,
minimum Android API 26. The three-part tag/version name retains compatibility with
the signed update protocol used since preview 0.1.2.

## Installation and updates

Download the `.apk` attached to a release and follow the Android installation
prompts. The app does not require Google Play to obtain the download. Android's
device and regional installation requirements still apply.

Install subsequent releases over the existing installation to retain app-private
settings, selected objects, the active target, filters, sorting and cached data.
Do not clear app data or uninstall as part of a normal update. Published updates
must retain the application ID and compatible signing certificate and increase
`versionCode`. From v0.1.2 the app checks public GitHub releases at every fresh
launch, including preview releases, and offers a newer compatible version.
The Repository island provides separate **Open repository** and **Check for updates**
buttons. Startup failures remain silent; manual checks provide localized feedback.
Installation always follows an explicit confirmation and Android installation prompts.
The original v0.1.0 needs one manual update to acquire this feature.

See [the update protocol](UPDATES.md) for signed metadata and verification details.

## Build and signing

The release build uses `:app:assembleRelease`, with R8 code and resource optimization
enabled in the release configuration from stable 1.0 onward. GitHub Actions checks the release build without
access to the distribution key. The unsigned APK is aligned and signed locally
with Android SDK tools; the final published APK is not debuggable or test-only.

At the owner's explicit request, Space Compass uses the same distribution
certificate as UVIR. This is a shared signature only: the apps retain separate
packages, preferences, caches and codebases. The private key and its passwords
are never committed, included in the APK or uploaded as release assets.

The public distribution certificate SHA-256 fingerprint is:

```text
9ddb005e9cf9758530f89666b9ab2801691608103194dd4cee50465e8f00741c
```

The inspected certificate subject contains project/generic information rather
than a personal legal name. Git author and committer metadata use the project
identity. These checks cover the inspected artifacts; they are not a guarantee
of anonymity across unrelated accounts or services.

## Release checklist

1. Check that the source tree is clean and the release version is correct.
2. Build debug and release APKs, run JVM tests, compile instrumentation sources
   and run release lint. Device UI checks are reported separately.
3. Align and sign the release APK, then verify its signature, package/version,
   non-debuggable manifest, alignment and certificate metadata.
4. Install an update on the phone and tablet without clearing their data.
5. Compute the final APK SHA-256. Generate and locally sign `space-compass-update.json`
   using `scripts/SignUpdateIndex.java`, then write `SHA256SUMS.txt` for both files.
6. Tag the exact source commit, upload the APK, signed update index and checksum to a draft release,
   verify the uploads and publish the release. Mark preview releases explicitly.

The source archives generated by GitHub correspond to the same tag. Version
1.2.2 also includes optional information/graphics ZIPs and a public validation
report, each listed in SHA256SUMS.txt. GPL and
third-party license notices remain in the source and APK. The downloadable
release assets include the signed APK, signed update index, optional packages,
validation report and checksums; private signing material
and unsigned/debug APKs are not published as release assets.

## Versioned graphics in 1.2.0

Publish `celestial-textures-v1.1` as a stable separate release with `make_latest`
set to `false`. It contains all eighteen pinned WebP images, its full manifest,
credits, complete ZIP and checksums. Verify each public download against the APK
policy before publishing v1.2.0. Preserve celestial-textures-v1 assets unchanged.
Only application releases are marked latest, so signed automatic updates find the app, not graphics.

news summaries deliberately remain those of 1.2.0 for this maintenance release.

pointing glyphs. Image pack 1.1 and its pinned individual URLs/hashes remain valid.

unchanged from 1.2.2. It refines compass notices and pointing/capture glyphs, and
clarifies the image export dialog. Its signed update index uses code 24 and the
exact 1.2.3 APK hash. Image pack 1.1 and older release assets remain unchanged.
